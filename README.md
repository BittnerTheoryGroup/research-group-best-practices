# Research Group Best Practices

Practical policies for computational research, reproducible paper production, research archiving, and responsible use of AI tools.

## Documents

- [`outputs/research-computing-policy.md`](outputs/research-computing-policy.md) — concise policy suitable for a research-group handbook.
- [`outputs/AGENTS.publication-policy.md`](outputs/AGENTS.publication-policy.md) — reusable policy block for a Codex `AGENTS.md` file.

The policy distinguishes exploratory, validated, and publication-level work. Publication-level work requires reproducible artifact drivers, machine-readable source data, verification, a paper-specific GitHub repository, and a versioned Zenodo archive with a DOI.

## Status

This repository contains a working group policy. Institutional legal, intellectual-property, ethics, research-security, and data-governance requirements take precedence.
